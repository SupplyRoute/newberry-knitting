# 뉴베리니팅

미국의 수제 털장갑을 소개하는 한국어 브랜드 홈페이지입니다.

## 실행하기

빌드 과정은 없습니다. 제품과 블로그 데이터를 `fetch()`로 읽으므로 `index.html`을 파일로 직접 열지 말고, 프로젝트 최상위 폴더를 문서 루트로 하는 로컬 서버에서 실행하세요.

## 구성

- 홈 / 브랜드 소개 / 제품 / 이야기 / 연락하기
- 반응형 모바일 메뉴
- `products.json` 기반 제품 목록과 스토어 구매 링크
- `story/posts.json` 기반 블로그 목록·상세·홈 최신 글
- 문의 폼 제출 피드백(데모)

제품을 추가하거나 수정할 때는 최상위 `products.json`만 편집하세요. `featured`를 `true`로 지정한 제품 가운데 앞의 3개가 홈에 표시됩니다.

블로그 글은 `story/posts.json`에 추가하면 날짜 내림차순으로 정렬되며, 홈에는 최신 3개가 자동으로 표시됩니다. 문의 폼은 현재 데모 동작입니다.
